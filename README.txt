GROWTH LOG - iPhone向け記録アプリ

内容：
- ランニング記録（距離・時間・練習内容・平均ペース自動計算）
- 雀魂記録（1日の順位別回数をまとめて入力）
- 月間カレンダー、月別集計、成長グラフ、レベル・経験値
- 端末内保存、JSONバックアップ／復元
- オリジナルの猫耳ドットマスコット（アプリ内のみ）
- アプリアイコンはランナー＋麻雀牌「發」

公開方法：このフォルダ内の全ファイルをHTTPS対応の静的ホスティング（GitHub Pages等）にアップロードし、iPhone SafariでURLを開いて「共有」→「ホーム画面に追加」。

データはブラウザのlocalStorageに保存されます。端末変更やブラウザデータ消去に備え、設定画面から定期的にバックアップしてください。
